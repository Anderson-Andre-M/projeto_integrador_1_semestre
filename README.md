Projeto integrador do primeiro semestre da Graduação em Análise e Desenvolvimento de Sistemas

|Código em processo de refatoramento|
-------------------------------------

Foi solicitado que eu desenvolvesse um sistema para uma clinica, onde tivesse as seguintes funções:

1- Inserir um paciente

2- Localizar um paciente através do nome

3- Mostrar a estatistica geral dos pacientes como: 
  Idade média,
  Paciente mais velho,
  Paciente mais novo.
  
4- Listar todos os pacientes e seus respectivos dados como:
  Nome,
  Idade,
  Telefone.

Utilizando loops, estruturas de decisões, Listas e Dicionarios para representar um paciente.

Hoje 31/03/2026, venho aplicando conceitos de boas práticas de programação no código pra melhor legibilidade e também para 
disponibilizar como parte do meu portifólio.
